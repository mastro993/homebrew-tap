# mastro993 Homebrew tap

Homebrew casks and formulae for apps by [mastro993](https://github.com/mastro993).

## Install

```sh
brew install --cask mastro993/tap/keyameleon
```

Or tap once, then install by name:

```sh
brew tap mastro993/tap
brew install --cask keyameleon
```

## Packages

| Name | Type | Description |
| --- | --- | --- |
| [`keyameleon`](Casks/keyameleon.rb) | Cask | Switches the Input Source to match the Physical Keyboard you type on. [Repository](https://github.com/mastro993/Keyameleon) |

Each app's release workflow updates its own cask in this repository.
